README 摘要

面向电网行业的 DSH 插件：Office 文档/表格阅读、编辑与排版；GB/T 4728 Visio 电网专业图（主接线、配电、拓扑、二次、变电站布置、地理接线、潮流、端子排）；CAD 转 PDF（图框分割、图签目录表、批量队列）。仅 Windows，MIT 协议。

  • Office：doc/docx/xls/xlsx/ppt/pptx 读取与导出 PDF，Word 结构化编辑、排版、模板与批量任务。
  • Visio：GB/T 4728-2022 符号库，九类图分派，接线校验与结构化错误码。
  • CAD：COM / ODA / PDF 三级链路，自动分割、合并、图号排序与图纸目录表。
