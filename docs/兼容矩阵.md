## 3. 已知限制（P1）

1. `pdfjs-dist` 加密 PDF 不支持（明确报 `E1011`），需先解密导出。
2. PDF 级图框识别基于「矢量矩形 + 标准图幅尺寸表」；扫描件/图片 PDF 无法识别（`E1012`）。
3. 合并/分割按图层顺序处理单层目录；多级子目录递归在 P3 扩展。
4. CAD COM 路径的纸型媒体名（`ISO_A4_(297.00_x_210.00_MM)`）随驱动/语言变化，旧版或中望/浩辰需在真机联调时按 `probe.ps1` 的 `cad.pc3` 与驱动实际媒体名校准。
5. 面板任务进度以 800ms 轮询 `suite.cad.status` 为准；Host→Client 事件推送（`registerRemoteEvents`）形状待实测，P1 未启用（R-03）。
6. PDF 图框检测假定页面 `/Rotate 0`（CAD 导出常见）；旋转页与多级子目录递归在 P3 校准/扩展。
7. 测试命令：Node 24 的 `node --test` 不接受目录参数，使用 `node --test "tests/**/*.test.js"`（等价于 `node --test tests\` 的发现范围）。

## 运维提示（2026-10-20 实测）

- **客户端面板生效条件**：DSH 的客户端模块表在宿主启动时扫描 dsh.client 声明，且“非客户端包”的否定结论按包名缓存到重启。若先安装了无 client 导出的旧版本，补上声明后必须**重启 DSH 主程序**（关闭并重新打开桌面应用），面板才会出现在侧栏。
- 升级已安装插件：插件管理器需先移除再安装（already-installed 拦截）；宿主侧插件条目即时生效，浏览器页面需刷新。
- 本机 git 推送依赖本地代理 127.0.0.1:7897（已写入仓库本地 .git/config，仅本机生效，不随库分发）。
