## 3. 已知限制（P1）

1. `pdfjs-dist` 加密 PDF 不支持（明确报 `E1011`），需先解密导出。
2. PDF 级图框识别基于「矢量矩形 + 标准图幅尺寸表」；扫描件/图片 PDF 无法识别（`E1012`）。
3. 合并/分割按图层顺序处理单层目录；多级子目录递归在 P3 扩展。
4. CAD COM 路径的纸型媒体名（`ISO_A4_(297.00_x_210.00_MM)`）随驱动/语言变化，旧版或中望/浩辰需在真机联调时按 `probe.ps1` 的 `cad.pc3` 与驱动实际媒体名校准。
5. 面板任务进度以 800ms 轮询 `suite.cad.status` 为准；Host→Client 事件推送（`registerRemoteEvents`）形状待实测，P1 未启用（R-03）。
6. PDF 图框检测假定页面 `/Rotate 0`（CAD 导出常见）；旋转页与多级子目录递归在 P3 校准/扩展。
7. 测试命令：Node 24 的 `node --test` 不接受目录参数，使用 `node --test "tests/**/*.test.js"`（等价于 `node --test tests\` 的发现范围）。

**已知限制 / 绘制口径偏差（P2 v1）**

1. **不设置 Visio Connection Points**：端子坐标为引擎内存表，连线用 `DrawLine`（首尾=两实例端子换算后的绝对坐标），图形正确、连接语义由模型承载（§4.3 步骤 5 既定，Connection Points 列 P3）。
2. **符号内文字不随实例旋转**：设备旋转 90° 时图元（线/圆）旋转，代号文字保持水平（避免 Visio `TxtAngle` 跨版本差异）；设备标签由引擎单独绘制。
3. **变压器二次侧绘制口径**：`visio-grid.ps1` 把二次侧连到 `toBay` 所在母线（避免连线穿越母线），校验口径（`ops/grid-model.js`）仍按 §4.1 规则连 `toBay` 末设备，两者电气连通性等价。
4. **母线宽度**：单线图母线按「各间隔列总宽（最小 240mm）+ 母联列 70mm」延展，不是整页通栏；多段母线等宽。
5. **环网多边形**：拓扑图环线按节点中心连多边形（直线段近似圆），线段会穿过节点图框；半径 `max(45mm, n×22mm/2π)`、非环节点径向分层 30mm/层照 §4.4。
6. **布局不做正交避让**：连线按端子坐标直连/两折点正交（feeder/fiber/cable），不做交叉最小化与绕障（P3 候选）。
7. **Visio 2003–2010 未实测**：保存失败时回退 `.vsd`（`SaveAs` 兼容分支已写，本机 Visio 16 未触发）。
