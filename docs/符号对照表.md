# GB/T 4728 电气图形符号对照表（v1 初稿）

依据：GB/T 4728-2022《电气简图用图形符号》系列（共 13 部分，2022 年修订版）。套件内置符号库按本表组织，`suite\symbols\` 下按标准部分分目录存放 JSON 几何定义，文件名与条目编号对应。

> 说明：本表为 v1 初稿。标准原文条款号须与纸质/正版标准逐条核对后，再写入符号定义文件的 `clause` 字段；核对状态见「状态」列。

## 实现与校验约定

1. 每个符号一个 JSON 定义：`{ id, clause, label, geometry: { shapes: [...] }, terminals: [...] }`，`clause` 未核对前置空；
2. 运行时由 Visio COM 在内存中组装 master，不依赖本机模具文件；
3. 支持挂接单位自备图库（.vss/.vssx），导入后同 id 优先用官方图形；
4. 每季度/发版前抽查核对一次标准条款（在 docs 记录核对日期）。
