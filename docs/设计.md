# DSH 办公·电网绘图套件 —— 设计文档

- 版本：v4.1（定稿）
- 日期：2026-10-20
- 目标平台：DSH Web / Desktop（以 DSH 0.2.1-rc.2 为基准，多版本自动适配）

## 1. 需求基线

① 占用小、速度快（后续调整为：体积不限，响应/运行速度优先）
② 项目文件夹内独立部署，官方 DSH 程序目录零写入，**一切修改限制在项目所在“2026”文件夹内**
③ DSH Web 与 Desktop 双平台、多个 DSH 版本可用，符合 DSH 插件标准，多种方式便捷下载安装
④ Office 文档与表格：阅读、编辑、排版
⑤ Visio 绘图：通用图 + 电网行业专业图，图形采用最新国网标准（内置按 GB/T 4728-2022，支持挂接单位官方图库）
⑥ CAD 图纸转 PDF：自动识别——单文件合并多图框自动分割为一页一图（A4 打印）；文件夹多张独立 DWG 自动合并为一个 PDF
⑦ git 全程管理，自动上传 GitHub 仓库，采用 GitHub 版本管理
⑧ 开源，符合开源协议（MIT）

## 3. 部署边界（2026 约束）

- 全部源码、运行时、输出、日志、备份、缓存、git 仓库均位于 `E:\工作\2026\...` 之内；
- 卸载 = remove_bundle + 删除项目目录，官方 DSH 程序目录零写入；
- 唯一例外（机制必需，待用户确认）：DSH 加载插件须在本机用户配置目录登记链接条目（`%USERPROFILE%\.dsh\profiles\desktop`，仅登记、不复制代码）。

## 5. 架构

```
对话工具: office_read / office_write / office_convert / visio_draw / cad_convert / suite_env
面板（三页）: 文档中心 │ Visio 绘图 │ 图纸转换   ——远程命令 commands→ 同一 Host 操作层
     格式模块: docx │ xlsx │ vsdx │ dwg │ pdf 处理（分割/合并/纸型适配）
     引擎链（启动探测一次并缓存，操作级降级，优先级可配置）:
       Office: COM(Word/Excel) → Python(项目内 venv/便携包) → 内置 officeToPdf 服务(转 PDF/渲染) → Node 只读兜底
       Visio : COM(Visio 16 实测可用) → .vsdx 直接生成兜底（老版本自动改用 .vsd）
       CAD   : AutoCAD/中望/浩辰 COM → 预装转换工具整文件转 PDF → PDF 智能分割引擎 → 无引擎提示
```

- 面板：`sidebar.panellist` + `main` 键控面板；文件浏览用 `workspaceFiles`；预览经 Host 注册的 `webServer` 路由；
- 面板→Host：`commands` 远程命令与对话工具同调一套服务方法（一份逻辑两个调用方）；
- 渲染/导出 PDF 优先复用 DSH 内置 `officeToPdf` 服务（doc/docx/xls/xlsx/ppt/pptx → PDF，零外部依赖，已实测确认其服务契约）。

## 6. 功能清单

- **阅读**：文档大纲/分页文本/表格数据；xlsx 工作表、公式与结果对照；页面渲染预览；对话 `office_read` 返回大纲摘要按需取全文。
- **编辑**：结构化指令（段落/样式/表格单元格、行列增删）；面板表单化操作；对话自然语言由 AI 转指令。
- **排版**：标题层级编号、字体字号、行距段距、页边距、页眉页脚、样式集、模板套用（自定义模板库）、批量排版。
- **转换**：导出 PDF、渲染预览、xlsx 公式重算校验（有可用引擎时）。
- **Visio**：通用图（流程图/组织架构/思维导图/时间线/泳道图）+ 电网专业图；COM 实时绘制并另存 .vsdx；对话 + 面板双入口，自然语言 + 结构化（JSON/大纲文本）双输入。
- **CAD**：场景 A 单文件多图框自动分割；场景 B 文件夹多图合并；图签图号提取排序；进度实时推送。
- **诊断**：设置页引擎探测状态、能力分级、一键诊断与日志导出。

## 8. 电气符号库

- 内置：按 GB/T 4728-2022 系列组织（如 GB/T 4728.7-2022 开关、控制和保护器件），JSON 几何定义 + 标准条款编号，运行时在 Visio 内存中组装成 master，不依赖本机模具；
- 导入：挂接单位 Q/GDW 官方图库（.vss/.vssx），导入后优先使用；
- 对照表：docs\符号对照表.md 维护“符号↔标准编号”。

## 9. CAD 转 PDF 设计

- **场景 B（文件夹合并）**：扫描（排除 ~$\*.dwg、.bak、.dwl）→ 逐文件转 PDF → 图号优先排序（回退文件名数字智能排序）→ 统一纸型合并输出。
- **场景 A（合并图纸分割）**：读模型空间 → 图框识别（块名清单 + 图幅尺寸表双重依据，去重聚类）→ Z 形/图号排序 → 逐框窗口打印（SetWindowToPlot + PlotToFile，DWG To PDF.pc3）→ 每框一页 → 目标纸适配（默认横向 A4）→ 合并。
- **PDF 级兜底**（无 CAD 或预装转换工具链路）：PDF 矢量解析 → 每页检测图框矩形（标准图幅 ± 容差、加长幅面系数）→ 裁剪拆页 → 缩放适配 → 排序合并。v1 支持矢量 PDF；纯扫描件图像识别列入 v2。
- 识别与排序规则全部可配置；用 tests-local 真实样例校准。

## 10. 版本适配层

- 探测矩阵：Word/Excel/PowerPoint/Visio（COM ProgID + CurVer + 安装键）、AutoCAD/中望/浩辰（ProgID + 版本键）、LibreOffice（soffice --version）、Python（py -0p）、预装 DWG 转换工具（常见路径）；
- 兼容分支示例：Excel 旧版无 SaveAs2 → SaveAs；AutoCAD 2010+ 内置 DWG To PDF，旧版挂 pc3；Visio 2003（.vss/.vsd）与 2013+（.vsdx）输出格式自适应；
- 每功能声明“最低要求 + 降级行为”，诊断页展示“本机版本 / 启用能力 / 被降级功能”。

## 11. 性能设计

- COM 会话复用（一次连接多次操作）、Python 常驻 worker（stdio JSON-RPC，免冷启动）、批量并行（默认自动，可配置并行度）、引擎探测缓存、面板订阅推送不轮询、预览按需渲染；
- 目标：常规读写 ≤2s；图纸批量 6–10 张/分钟；长任务后台执行实时进度。

## 12. 标准合规与分发

- **bundle 标准**：`package.json` 声明 `dsh.bundle.patch`、`engines.dsh`（基准 0.2.1-rc.2，随兼容矩阵调整范围）、`files`、`exports`（locale/icon）；cordis.patch.yml 行 id 唯一；Host 插件用 `apply(ctx, config)` + `inject` + `Config`；Client 用 `dsh.client`（platform/inject）动态模块 + 插槽注册；meta 标题描述中英双语；原创图标；只在公开扩展点上构建。
- **四种安装渠道（Web/Desktop 通用）**：
  1. 市场索引（推荐）：GitHub Pages 发布 `index.json`（格式对齐官方 `dsh-plugin-catalog` 索引，实现细节以 `@deepseek-ai/dsh-plugin-market` 包为准），用户在插件市场添加索引后，发现页一键安装/升级；
  2. GitHub Releases：发布 npm 打包 tgz + 校验和 + 便携 Python 资产；
  3. npm 发布：包名安装；
  4. 本地：`tools\install.ps1` 链接安装。
- 版本豁免机制遵循 DSH 规则：engines.dsh 不匹配时安装被拒，避免装上即崩。

## 13. 安全

默认仅读写会话工作区（本项目即“2026”内）；访问外部路径需用户批准；修改前自动备份（默认最近 3 份，存 runtime\backups）；子进程经 Harness `subprocess` 服务在沙箱内运行；预览/下载路由带会话授权；PAT 等密钥仅存本地（git 忽略），绝不入库。
