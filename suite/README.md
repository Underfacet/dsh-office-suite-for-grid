# dsh-office-suite-for-grid（套件本体）

DSH 办公·电网绘图套件的插件本体（v0.1）：

- 工具：`suite_env`（环境探测）、`office_read`（Word/Excel 读取，COM 引擎）、`visio_draw`（Visio 流程图，COM 引擎）；
- 命令：`office-env`；
- 引擎脚本位于 `engines\`（PowerShell），随包分发、就地执行；
- P1 起加入 Client 面板、其余图类型、CAD 转 PDF 与排版功能。

安装：经插件管理选择本目录（链接安装，代码留在本地）或从市场/Release/npm 安装打包版本。
